# 公开端浏览器界面

Dioxus 客户端渲染的公开端 SPA。路由集合按旧版 Auction-BF 的
`manifests/public.routes.json` 冻结，共 14 条，修改前必须先确认外部 URL 契约。

- `src/main.rs`：薄启动入口。
- `src/api/`：按 session、账户、规则、黑名单、只读查询、实时事件和命令职责拆分的同源 Public API DTO 解码与请求，
  不接触存储模型。
- `src/app/`：按 session、账户、规则、黑名单、只读页面、实时事件和命令组件拆分的公开端路由表、外壳与页面组件。
- `assets/public.css`：公开端 surface 样式，沿用旧版公共拍卖页的 BEM 类名与视觉契约。
- `i18n/*.ftl`：5 种语言的 Fluent 译文（`en`、`zh-CN`、`zh-TW`、`ja`、`ko`），默认英文。

## 国际化

所有用户可见文案都经 `t!` 从 `i18n/*.ftl` 取用，组件里不得硬编码字符串。译文以
`include_str!` 编译期内嵌，首屏不额外请求语言资源。

Fluent 消息 ID 不允许包含点号，旧系统的 `nav.home` 一类键改为 `nav-home`。

`t!` 在键缺失时 **panic**，因此新增文案必须同步更新全部 5 个 `*.ftl`；缺一种语言就会让该
语言下的页面崩溃。语言集合、偏好持久化和 `<html lang>` 同步由 `auction-web-shared` 提供，
本 crate 只拥有自己的译文。
  设计变量来自 `auction-web-shared`。

构建：

```bash
just web-build-public   # dx build -p auction-web-public --platform web
just web-serve-public   # 本地开发监听
```

产物输出到 `target/dx/build/auction-web-public/web/public/`，由 `auction-http` 内嵌进
公开端二进制。未构建产物时后端仍可编译，静态路由返回 503。

当前首页看板、lot 详情、规则文档、公开黑名单、竞价日志、价格历史、Public session、账户竞价/代理读取、live lot
普通出价和持久化实时事件游标页已经通过同源 HTTP 读取或提交 Public API；lot 详情现在消费完整装备安全投影，展示
分类、等级、属性、平均 roll、游戏链接和按 lot 分页的竞价历史；公开端已补齐独立品牌导航、拍卖摘要、
状态徽章、拍卖与 lot 倒计时、竞价表单和文档/空状态的统一视觉层。首屏使用内联启动骨架，CSS 由静态 head 预加载，
倒计时会根据 HTTP `Date` 头估算服务端时钟，超过 24 小时按 `Xd HH:MM:SS` 展示，closing 提示在剩余 15 分钟内出现，
过期状态显示本地化的收尾文案，缺失或非法时间显示 `—`，避免客户端本地时钟偏差造成误导；
页头实时连接徽章恢复旧版的圆点、raised 背景和统一边框，并按 checking/connecting/connected/error 状态着色；
避免空白根节点和样式到达延迟造成的闪烁。已认证会话会让实时页自动订阅只读 WebSocket，当前拍卖页还会订阅对应的
`auction:{auction_id}` 流，只消费安全事件信封，并在服务端要求权威快照时停止推进。加载、错误、空数据和命令确认状态均
使用五语言资源；出价、代理、登录和退出操作会锁定控件并显示明确的忙碌、成功或失败反馈。拍卖看板通过 URL 保留
`world`、`auction`、`type`、`page`，历史列表通过 URL 保留 `world`、`status`、`page`，并支持当前预览与上一轮已结算拍卖
之间的切换；竞价表单已支持旧版金额缩写、最低价提示、幂等重试、代理终态重建和最终阶段限制；实时客户端会校验事件信封、
schema、连续游标，并在断档或服务端要求时回到权威快照。公开发现范围使用持久化
`auction:discovery` 派生流，可跨进程恢复；lot 详情、竞价历史、代理加载和实时状态失败时提供可恢复重试；Public 进程使用持久化 relay 和有界进程内 Hub 向
WebSocket 推送，慢连接会被淘汰，客户端仍以游标 catch-up 为权威恢复路径；Public 登录页已按旧版清理一次性 key、保留 1024 字符输入边界，
按错误码和安全公开原因显示本地化反馈；页头已补齐匿名登录/我的竞价入口、认证用户名和退出菜单，登录/退出会刷新账户与实时会话状态，
`/me` 现在承载旧版的竞价账户页，匿名时显示登录 CTA，普通竞价与代理授权使用独立分页并保留 `bid_page`/`proxy_page` URL 状态，
账户行提供拍品链接、金额/时间格式化、代理授权历史和安全状态文案；`/account` 保留为兼容别名并无历史记录跳转到 `/me`。旧版没有外部广播 relay/sink；若未来新增，它属于独立扩展，
不改变当前 Public 本地 Hub 的等价边界。`/bidlog` 已对齐旧版的场次选择、历史分页、拍品链接、代理标识、有效行高亮和移动端表格布局；
`/history` 已补齐旧版的 world/name/日期/价格/买家/卖家筛选、URL 状态、成交统计、拍品与拍卖链接和分页。
拍卖目录窄屏字段标签恢复旧版的自然宽度，不固定为 `5rem`，避免多语言标签挤压数据列；表格字段、`data-label`
和竞价动作契约保持不变。
普通竞价与代理弹窗恢复旧版的首个输入框聚焦、Escape/遮罩关闭、`aria-modal` 内 Tab 焦点循环、
背景滚动锁定和关闭后触发按钮焦点恢复；这些是浏览器交互边界，不改变竞价命令、幂等或资格校验。
金额输入恢复旧版的即时解析反馈，并正确区分一位和两位 `M` 小数（例如 `1.5M = 1.5M`）；超出
浏览器 JSON 安全整数范围的输入会在提交前失败关闭，服务端金额与资格校验仍是最终权威。
弹窗标题重新携带 lot code，表单恢复旧版紧凑宽度、纵向布局、取消/提交动作组，以及带完整说明的
Fast/Slow 单选模式；最终阶段的 Slow 禁用原因通过对应控件的可访问说明公开。
登录用户的 lot 详情也恢复旧版“我的代理出价”摘要，展示服务端投影的上限、模式、配额、可用动作、
完整变更历史和状态；活动授权的动作按钮明确显示为“降低代理上限”，加载失败可以原位重试。
普通竞价被服务端接受后会按旧版立即关闭弹窗并刷新权威拍卖快照；失败时保留弹窗和稳定命令 ID，
代理授权成功则继续在弹窗内展示是否领先、当前状态、配额和完整授权变更历史，权威数据刷新不会
覆盖这份命令结果，用户明确关闭后才恢复触发按钮焦点。
本 crate 只允许依赖稳定 HTTP DTO 与 `auction-web-shared`，不得导入存储、配置、凭据或管理端
组件。
