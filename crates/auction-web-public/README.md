# 公开端浏览器界面

[文档导航](docs/README.md) · [Public 设计](crates/auction-web-public/DESIGN.md) · [架构](docs/design/architecture.md) · [契约](docs/contracts/README.md)

Dioxus 纯客户端渲染的公开端 SPA，拥有公开读取、竞价交互、会话与实时恢复。只消费稳定 HTTP/实时契约和共享浏览器能力，
不依赖 Admin UI、存储模型、配置或服务端密钥；页面结构、视觉与交互详见 [Public 设计](crates/auction-web-public/DESIGN.md)。

## 职责与实现边界

15 条浏览器路径由 Route、[后端入口清单](crates/auction-http/src/assets/routes.rs)和[路由契约](docs/contracts/routes.md)共同维护。
`main.rs` 为薄启动入口，`app/` 与 `api/` 按同一业务 owner 分组；`auction/watches/` 拥有整场装备标记读取、原生命令按钮
及账号隔离缓存（对应传输在 `api/auction/watches.rs`），`app/identity/watch_preference.rs` 与
`api/identity/watch_preference.rs` 拥有账号竞价警告渠道表单与严格解码，账户页以用户 UUID 隔离宿主。
公开响应与实时帧的 UUID 规范形式在栈缓冲中核对，保留非零、版本与 RFC4122 variant 校验，避免逐字段临时字符串分配。
整场标记、账号偏好、会话及论坛 UUID 校验也使用相同栈缓冲方式；各自原有 UUID 版本与非零接受边界保持不变。
普通出价与代理命令的成功响应均核对请求 lot UUID；错目标返回 `invalid_response`，沿用未知结果冻结与原命令重放。
装备属性在严格解码中只校验一次，保留必填、可选及未知字段规则。
`app/identity/account/watches/` 拥有当期标记列表的只读组合、账号/世界隔离、完整目录读取与本地分页展示。
`api/identity/registration.rs` 只在登录页读取 P29 的配置账号安全投影，`app/identity/session.rs` 将名单作为纯文本
插入五语注册提示；不把示例账号或完整运行配置编入 WASM，展示与失败边界见[Public 设计](crates/auction-web-public/DESIGN.md#6-竞价与代理交互)。
`surface/board/refresh.rs` 拥有资源失效与合并读取，`auction/commands/` 按普通出价、代理创建/降额、确认及未知结果
重试拆分，`surface/pagination/` 统一各列表的数字分页、正整数数量与译文（`preferences.rs` 拥有 Public 本地数量偏好）。
`surface/catalog/columns/` 拥有装备目录的列显隐、默认权重、内联设置面板与本地展示偏好；不向 API 增加字段选择参数。
`surface/catalog/filters.rs` 拥有分组与等级表单，`api/model.rs` 的 `CatalogLevelFilter` 只做浏览器查询解析及响应归属校验。

论坛页先读取独立同步开关：明确关闭不挂载帖子轮询，未知状态不能当关闭；启用后只展示同步摘要、真实处理楼层和
更新时间，正文、版本与诊断细节归 Admin，公开页不提供手动重试按钮；帖子读取失败后暂停该场帖子轮询，重新进入页面时重读。
同步开关即使关闭或暂时失败也每 30 秒复核；开关与帖子轮询等待共享可见性，隐藏期间不继续周期请求，恢复可见后继续；
帖子读取和轮询显式依赖拍卖 UUID，响应同时绑定该身份，旧成功或错误不能串到新场次。
首页不读取论坛状态，`/status` 只作静态说明。目录、历史和账户的筛选/分页通过 URL 恢复，响应须与当前选择身份对齐；
请求按所选数量交给后端分页，不在浏览器下载全量后切片（`api/decoder/` 仅为 `page_size` 接受完整正 `i64`，
金额与版本仍保留既有安全整数校验），具体数量与展开规则见
[Public 设计](crates/auction-web-public/DESIGN.md#5-表格与信息密度)。
Public 查询同时订阅 Router 完整位置，普通链接与同路径 query 跳转均同步页头世界、页面读取与实时目标；
关闭世界只纠偏当前入口，不改写历史筛选或指定场次深链。分页用户操作使用 Push，服务端总数收缩后的页码纠偏使用
Replace，避免浏览器返回被无效页卡住；账户竞价/代理列表须同时匹配本次两个页码，重读期间不把旧行显示在新页码下。
账户竞价/代理列表及本人代理读取把稳定宿主 UUID 作为 `x-auction-expected-user-id` 随每次 GET（含原有重试）发送，
由服务端在当前 Cookie 认证后复核；`session_changed` 触发权威会话重读，不把新账号响应接到旧宿主。
本人代理快照另绑定请求 lot UUID，只有匹配当前标的的完成结果才能进入摘要和确认表单。
竞价记录的世界目录与记录页分别保留请求身份，往期拍卖列表同时绑定世界、状态、页码和数量，指定历史拍卖绑定请求 UUID。
v1/v2 拍卖列表完成严格解码后统一核对请求页码与数量；历史场次查找、竞价日志选择器及预览切换也经过同一门禁，
错页响应返回 `invalid_response`，不拼入跨页结果。
往期拍卖提供世界与状态选择，默认已结算，也可查看进行中及最终阶段；筛选变化回到第一页并写入 URL。
筛选器在加载、失败与重试期间保持挂载；历史链接指向已关闭世界时仍显示该世界的实际选择。
黑名单、补偿池批次、lot 竞价历史及账户列表先核对请求分页，再展示成功、空结果或错误；切换条件时旧响应不能展示为新条件的
结果，也不能触发新页码纠偏。同一查询的后台重读继续显示已完成快照。lot 详情按 UUID 重建宿主，避免 Router 复用组件时
沿用首次捕获的目标和命令状态。
需要销毁状态的账号读/偏好、标记上下文、lot 路由、历史分组和标记表分页使用真实 keyed iterator，
key 只绑定各自业务身份；同查询正常刷新复用状态，暂时会话错误不清理稳定宿主中的未知意图。
预览/历史切换的辅助资源随权威刷新更新，结算目录先按同一世界请求，避免其他世界占满前 200 条。
竞价记录页先刷新所选世界的 `live`／`final`／`settled` 场次，再读取所选记录；已结算历史深链保留目标场次，
不因结算而纠偏到进行中场次。拍卖历史“查看”列保留原有拍品、出价记录入口，新增真实论坛主题链接，使用 P30 v2 一次读取本页地址，
不逐行调用 P15 或读取镜像正文；P07 v1 保持原字段，详见[版本契约](docs/contracts/routes.md#p30-v2-拍卖历史与论坛地址)。
出价记录和装备详情竞价历史都展示服务端完整公开事实，不合并普通报价与代理回应；
`BidHistoryParticipant` 明确标记普通/代理来源并保留论坛楼层链接，两处表格复用五语竞价日志标题作为仅屏幕阅读器可读的 caption，不显示额外说明文案。
领先状态使用“当前领先／当前未领先”，不把被立即超过的已接受报价称为无效。列表、total、排序及分页语义见
[历史读取契约](docs/contracts/routes.md#标的编号来源与历史读取)。

目录顶部先显示“装备分组：全部／稀有／融合”，再显示装备类型筛选；当前、预览及历史某场目录共用。
分组同行提供紧凑等级上限输入与“显示无等级装备”复选框；上限默认留空不限，无等级默认显示，不提供独立应用按钮。
回车、离开输入框或勾选变化时应用当前有效草稿；等级条件、分组与类型在服务端分页前组合，变化回第一页。`max_level`、`include_unleveled=false`
和 `equipment_group=rare|fusion` 随 URL 恢复；非法等级条件保留错误并阻止读取，输入在加载或失败时保持挂载。
列表装备列仅显示装备名称，后续按“分组 → 平均 Roll”排列；分组列以文字显示稀有／融合，详情在装备事实中显示分组；
装备名保持原样式，论坛上色规则由服务端判定。
详情在桌面按“装备分组、分组值、标记按钮、分类、等级、平均 Roll”横排；手机改为字段卡片，分组与标记占满整行，其他事实分两列。
两端沿用同一份事实与标记控件，状态与同步门禁保持一致。
严格解码只接受服务端 `equipment_group=rare|fusion`，预览详情同时核对摘要与装备分组；类型计数取当前分组及等级条件内总数，
目录快照身份包含全部筛选，后台刷新、翻页和浏览器返回均保留并核对当前选择；响应漏筛时报错，不在本页二次删行。

目录操作列由 `surface/catalog` 按权威拍卖状态控制；已结算场次同步移除列宽、表头及行单元格。
默认全显时，实时/已结算/预览分别为十三/十二/十一列；装备类型与“显示列”固定为同一网格行的左右两列，
桌面类型标签与按钮在首行垂直居中对齐，类型选项内部可折行；手机装备分组与类型改用原生选择器（类型带同一计数），标签同排，右侧保留同一“显示列”按钮。
列设置采用紧凑顺排选项，桌面控件为 28px、触控端恢复 44px，恢复全部/关闭操作与标题同行，保留原生复选框与可见焦点；具体密度见 Public 设计。
偏好只保存于当前浏览器，切换布局无可见列时临时保留装备列；可见列按原权重归一化为完整 100% 宽度。
隐藏操作列不卸载命令宿主，隐藏剩余时间停止该叶子的秒级订阅；筛选、分页和权威读取不受影响。
匿名“登录后出价”与“登录后标记”共用按钮视觉、可见焦点和触控尺寸，保留原生登录链接及原返回位置，不改变认证或命令门禁。
`surface/board/data.rs` 按账号、世界、场次、阶段及筛选分页隔离目录快照；预览后台重读期间保留已对齐的
完整目录，新修订对齐后无提示替换，首次读取、上下文切换与明确失败继续提供原有反馈。

## 手机浏览器布局

设备展示分成 [desktop.rs](crates/auction-web-public/src/app/surface/presentation/desktop.rs) 与
[mobile.rs](crates/auction-web-public/src/app/surface/presentation/mobile.rs)：桌面使用完整导航、类型标签与账户章节链接，
手机使用可展开导航、原生装备分组/类型选择器与账户章节折叠入口。手机断点为 `width <= 48rem`，或 `width <= 64rem` 且
`pointer: coarse`；其他屏幕使用桌面展示，`width > 64rem` 再启用桌面紧凑密度。

[public.css](crates/auction-web-public/assets/public.css) 拥有设备无关的颜色、组件与表格规则；
[desktop.css](crates/auction-web-public/assets/desktop.css) 拥有桌面密度；
[mobile.css](crates/auction-web-public/assets/mobile.css) 拥有手机布局及触控尺寸。三个文件独立作为静态 CSS Asset，
均先声明 `@layer foundation, surface, desktop, mobile;`，分别写入 `surface`、`desktop`、`mobile` 层，
不依赖 Dioxus 的 head 标签顺序，也不使用不会被打包器合并的本地 CSS `@import`。

CSS 只切换纯展示控制的可见性；两端复用同一查询回调，目录计数只计算一次。世界选择、会话、业务表格、登录/历史/
账户偏好表单和页面级命令宿主均只有一份，不按窗口宽度改变 key 或重挂载，不增加读取或 resize/User-Agent 监听器。
隐藏的展示控制退出布局及键盘顺序，交互 ID 不重复；打印隐藏两端导航，只保留共享内容。

页头、内容与启动占位避让安全区，页面使用动态视口高度并保留缩放。手机业务表复用同一 DOM，按记录显示卡片：字段分两列，
名称和操作占满整行；字段标签沿用五语 `data-label`，表头视觉隐藏但供辅助技术读取，用户选择的列仍生效。长名称、时间与金额可折行，目录出价／代理并排，标记另起一行。装备详情事实也改为字段卡片。
公开页与启动占位统一使用完整可用宽度与左右各 12px 的边距，遇系统安全区取较大值；规则、论坛、登录不再收窄页面。桌面与打印保留原生百分比表格，Markdown 不转卡片。
手机顶栏按 DOM 顺序排成品牌与图标开关、世界／语言／主题三等分、连接整体／会话整体各半三行；连接状态与刷新、会话两项各自等宽分栏，用户名单行省略。
Public 与 Admin 的分页统一使用共享样式，手机与 PC 一样单行显示页码窗口、总数与每页数量（32px），自定义数量与跳页仅 PC 提供；
顶栏触控目标至少 44px 高，输入字号至少 16px，详见[共享组件](crates/auction-web-shared/README.md)。
账户页五个顶层分区统一为同一卡片外观，宽屏按对齐的 2:3 网格并排展示设置分区及出价／代理列表；空或单页隐藏分页控件，仍保留
页码纠偏与稳定表单宿主。手机保留章节跳转、两列偏好选项和可换行的保存按钮，详见 [Public 布局](crates/auction-web-public/DESIGN.md#3-外壳与布局)。
成交历史的高级条件底部提供同一表单的提交入口，
竞价记录的拍品筛选与场次标题同排，窄屏可换行；往期拍卖筛选允许收缩。Key 登录表单缩窄居中，提示允许长机器人名称换行，输入与错误/帮助文字显式关联。
拍卖历史“查看”链接在表格单元格内独立折行，手机与触控设备保留 44px 高的点击目标。
弹窗动作按可用宽度排列；普通竞价保留整数数字键盘，代理上限保留 K/M 文本输入。
登录失败焦点、筛选面板 Escape 关闭及字段错误描述遵守 [Public 交互设计](crates/auction-web-public/DESIGN.md)，
只调整浏览器交互与输入语义，金额、查询和会话契约不变。
共享层继续拥有弹窗焦点、滚动锁、视口与输入字号；命令确认、幂等和权威读取不随布局改变。

## 国际化

业务文案统一通过 `t!` 读取本 crate 的 `i18n/*.ftl`，默认 en、编译期内嵌；消息 ID 不含点号，新键同步五种语言，
缺键会 panic。`hv.lang` 和 `<html lang>` 由共享层维护；规则请求把 locale 同时作为资源依赖和结果身份，
语言改变时旧正文及旧错误立即退出展示，同语言后台刷新可保留已完成快照；正文用安全 Markdown 展示。

## 派生数据与解码

查询字段的 memo 借用状态，只复制实际需要的字段；账户和成交历史展示直接消费已拥有的行集合，不再次深克隆整页。
目录展示行从已拥有的 lots 移出装备字符串，快照只保留响应元数据与共享展示行；
账号完整标记读取复用同一消费式投影，不同时保存两份装备正文。
外壳、看板、账户与论坛在渲染期间借用资源快照，只复制传入子组件所需的数据；
竞价记录的场次选项直接借用已匹配世界的列表，记录与详情历史行消费已拥有的集合和字段，不再重复深复制。
竞价记录选择器最多并发读取 live、final、settled 三路目录，各状态内部按编号顺序逐页读取；
沿用总数或短页结束、按场次号与 ID 倒序排序及按拍卖 ID 去重。任一路失败即取消其余读取，
共享传输的 AbortController 同时取消尚未完成的浏览器请求。
成交历史名称校验单次遍历词片段，不分配临时词数组，保留总长、词数、单词长度和控制字符的错误优先级。
成交历史分组先借用行内标签查找，只有新组才复制标签；保持首次出现顺序与组内顺序，避免为每条重复记录分配临时名称。
预览开场检查借用已保存的场次/时间标识比较，不再随秒针复制该字符串。
成功/错误信封从已拥有的 JSON 移出 `data`，成功值仍先执行原始字段及跨字段校验，再规范化兼容整数；
这只减少复制，不放宽响应接受边界。

## 构建与资源边界

```bash
bash ci/release/web-bundle.sh public
```

该任务使用 `dx bundle`，复制到 `target/dx/build/auction-web-public/web/public/`，供 Public 的显式 `web-embed` 制品内嵌。
无 SSR/hydration、独立 JavaScript 业务代码或第二套前端构建链；后端保留 `allow_missing`：无产物可编译，已登记页面
返回 503，未知路径保持 404（见[开发指南](docs/guide/development.md#浏览器与发布构建)）。

## 权威数据与命令交互

目录、lot、规则、账户、价格历史等均读取同源 API，不使用会被误认成权威数据的示例行；服务端 capability 决定动作，
空装备链接不生成伪造 URL，完整游戏链接只消费受限 DTO。补偿流水复用目录的完整 ID/key 链接校验，
不能把带 10 位 key 的合法链接当作无效响应；字段可省略，提供时不接受空串或 keyless URL，见
[读取契约](docs/contracts/routes.md#公开读取与命令结果)。普通出价使用整数 K 输入，代理支持约定的精确缩写，
新命令最高 1B，服务端仍是金额、资格和状态的最终权威；提交前确认，失败保留冻结输入与命令 ID，结果未知只能重试原请求。
当下一口要求超过 1B 上限时，目录和详情显示禁用原因，提示文字可折行。
[catalog/command_scope.rs](crates/auction-web-public/src/app/surface/catalog/command_scope.rs) 与
[watches/commands.rs](crates/auction-web-public/src/app/auction/watches/commands.rs) 在异步读取分支之外持有页面级命令，
按用户/lot 隔离；GET 错误、Pending、阶段及分页变化不销毁未知状态，仍有可见原样重试入口。
临时会话读取失败保留宿主但禁止新写，明确换号、退出或离开页面才清理；清理不表示服务器请求已取消。
详情和目录在 Live/Final 均保留合法竞价、Fast、授权降额及标记，新建 Slow 仅允许 Live。

补偿流水只展示真实收支并保留独立分页，不显示期初/期末占位条目或内嵌结算计算式。
批次与流水表沿用历史表的容器、字号和表头样式；展开按钮复用 `public-history-group-toggle`，余额卡按内容收紧。
历史成交价搜索区固定在页面顶部的独立全宽容器，不随下方结果表的列宽或字号适配变化；页面只保留隐藏的可访问标题，移除可见大标题和说明。
历史成交价的搜索、筛选与显示控件沿用共享紧凑尺寸，手机保留触控高度；查询和未提交草稿保持原行为。
补偿批次直接消费已拥有的行集合，只向展开批次传递流水页；折叠行不复制或持有整页流水。
补偿装备外链以完整名称作为链接提示和可访问名称，内部文本不再生成嵌套的独立按钮。
即使当前流水页只含被隐藏的期初／期末占位，手机仍保留可访问表头及原分页状态。
提交筛选后才读取和展示成交列表，带筛选 URL 可直接恢复结果。名称按服务端相同的空白/逗号拆词、8 词、每词 128 字节和总计
1024 字节边界校验，离开字段或提交时显示五语字段错误，输入时清除错误。年月未改变时保留 URL 原有日期端点，单一清空
动作移除已应用条件并收起结果区；成交行在装备名旁显示原分类标的号，期数、等级和精确成交金额仍取权威 DTO。
成交历史的未提交筛选与字段错误在翻页或更改结果排序时保留；实际筛选条件变化时仍按 URL 恢复。
名称片段以字面包含且全部命中，例如 `Leg Sav Pow Hel Bal` 可匹配各片段所在的完整装备名。
名称 URL 的非法值保留为可修正的字段错误并阻止请求，纯分隔符按空词集合处理，避免丢弃条件后扩大查询。
金额支持 C 整数、K 最多三位小数、M 最多六位小数，使用 checked 整数运算统一为 `0..=9007199254740991` C；
URL 中任意合法整数 C 均无损恢复，非法金额或倒置区间保留字段错误并阻止查询。`history_sort` 保存时间/价格四种全结果排序，
变更排序回第一页；`history_group` 仅控制本页按装备名、买家或卖家分组，默认按装备名分组，切换分组不重取成交页。
每组以独立结果框显示名称和真实本页笔数，可展开收起，框内保留既有九列表格；统计仍覆盖全部匹配成交，精确中位数优先使用可选 `median_exact`。
买卖家名称提供完整玩家名的快捷筛选并保留其他条件，未知卖家占位不生成筛选动作；清空同时恢复默认排序与装备名分组。
展示控件与本页分组由[成交历史展示模块](crates/auction-web-public/src/app/auction/reads/history/presentation.rs)拥有。交互参考
[AmyBotV2-web](https://github.com/anon962/AmyBotV2-web/tree/385c546bee177d945f0fae64041f936cd415a530)
（MIT，2024 anon962），由本项目 Rust 独立实现，构建输入仍仅依赖本仓库。
布局与分页规则见[Public 设计](crates/auction-web-public/DESIGN.md#5-表格与信息密度)。

装备标记：整场通过 `GET /api/v1/me/lot-watches?auction_id=<uuid>` 读取完整集合（上限 10000 条，超限失败而非截断），
`PUT /api/v1/lots/{lot_id}/watch` 使用冻结的 `PublicSetLotWatchRequest`，`channel=mm` 保留为兼容占位。按稳定 user UUID +
auction UUID 隔离 `localStorage` 非敏感缓存（无登录不做本地匿名标记），缓存仅用于展示；同步过程不显示加载或缓存提示，加载中或失败时
不能用旧版本修改；取消的 false 墓碑原样保存，命令成功后随既有刷新代数重读服务器集合，不从代理 GET 推导标记。
整场读取只构造一次按 lot UUID 索引的内存快照，权威结果与展示缓存通过 `Rc` 共享，避免每行线性扫描与整页深复制；
本地持久化仍保存原 DTO，版本校验及缓存不能提交命令的边界不变。
整场读取在异步请求前后借用当前身份复核，不订阅会话截止时间；同账号续期不再取消并重发集合 GET。
未知结果保留完整原命令供重试，409 必须由用户刷新、检查状态再修改（见[标记设计](crates/auction-web-public/DESIGN.md#61-装备标记与超价提醒)）。

`/me` 的[当期标记列表](crates/auction-web-public/src/app/identity/account/watches)按各启用世界读取当前场次，包含 preview。
现有完整标记集合与当前公开目录求交，显示真实装备名、分类编号、世界场次、标的状态及详情链接；撤回等非公开标的沿用目录可见性。
目录按 200 条完整分页，检查场次、公开修订、每页总数与重复标的，最后最多并发两路读取复核当前场次和完整标记版本；
版本索引与选中集合借用响应中的标的 ID，复核通过后才返回完整结果。
既有 offset 10000 上限下最多读取 10200 条目录，超界、变化或读取失败显示错误与重试，不展示部分结果。
标记有效集合为空时跳过目录读取；最终匹配结果按真实总数每页 10 条，分页独立于竞价/代理页码。
完整标记结果在读取完成后以 `Rc` 共享给表格，翻页只借用当前十行并复制展示所需字段，不深复制全部装备。
总数收缩（含归零）时保留 `AccountPager` 宿主，并传入原请求页码完成纠偏，避免总数恢复后跳回过期页码。
按账号 UUID、世界与场次隔离；后台同步保留同账号/世界的已完成结果及分页，新结果返回后替换，新场次重建分页，
身份变化立即隐藏。列表不订阅普通竞价通知，会话重读不触发目录重读，不从本地标记缓存补装备数据。
已知世界的装备详情入口保留 world；裸 lot 链接及冲突 query 通过现有拍卖读取解析权威 auction 身份，
实时目标按 Lot/Auction 请求身份隔离，不因 query 缺失默默订阅 Main。身份读取失败明确降级，原 60 秒读取仍作兜底。

账号渠道：`/me#outbid-notifications` 顶部提供统一的 MM/论坛 PM 单选与显式保存，
`GET/PUT /api/v1/me/lot-watch-preference` 消费 `PublicLotWatchPreferenceResponse` 与
`PublicSetLotWatchPreferenceRequest`，拒绝未知/缺失 data 字段、身份不符及非正 i64 版本，整数不经 JS 浮点转换。
权威 GET 前禁保存，不用本地默认值冒充服务器结果；PUT 冻结完整 payload、command_id 与 CAS 版本，成功或幂等重放后
GET 当前状态，离开/重载先 GET、不自动重放，待定命令不写入 localStorage，身份变化或登出销毁旧命令。
两项账号偏好宿主与外壳 `PublicCommandOwner` 的稳定身份绑定，位于会话加载/错误分支之外；临时会话读取失败不销毁
草稿、进行中的提交或未知命令。新写要求本次会话读取完成且身份一致，已有未知结果仍可原样重试；
响应收口核对稳定宿主，不能因会话 GET 瞬时失败而把 `busy` 永久留置。身份前置条件仍由服务端当前 Cookie 与冻结用户 header 复核。
偏好只影响已标记装备的后续反超警告（每领先周期一次，不影响结算/COD），保存成功不保证可送达；论坛 PM 需已绑定的
论坛账号，不可投递不会自动改发 MM。当前世界选择只提供 enabled world；历史 URL 可显示已关闭世界的只读选中项，
历史筛选仍可访问已关闭世界的 settled 事实；
倒计时通过 HTTP Date 估算服务端时钟，仅用于展示。目录、页头及详情复用同一倒计时 hook，
仅在截止文本变化时解析 RFC3339；秒针仍重新读取校时结果并生成当前语言文案，隐藏目录剩余时间时释放订阅。

登录时长：`/me#login-duration` 的 [session_preference](crates/auction-web-public/src/app/identity/session_preference) 拥有原生永久/
自定义表单、分钟/小时/天精确换算和账号隔离的命令宿主；默认永久，具体范围见[登录时长契约](docs/contracts/routes.md#p27p28-登录时长)。
保存应用于当前与后续登录，不改其他会话；当前实际截止独立展示，不能从账号偏好推断旧会话已经永久。
GET 成功前禁写，未知结果冻结原 command_id、时长与版本；成功后重读偏好并广播权威会话重读，不用历史重放结果伪造身份。
会话截止严格接受成对 `null` 或有序 RFC3339 时间；有限会话到期后重读一次，永久会话不设置到期计时器。
`api/identity/session/cookie.rs` 拥有显式浏览器期限同步，普通会话 GET 不写 Cookie。
登录、退出、偏好保存和同步共用同源原生 Web Locks，要求安全上下文及原生 API；缺能力/等待超时显示五语前置错误，
不生成假锁或自动重试。同步提示只有一条无凭据的用户/期限投影，不参与认证；期限和升级边界见
[P06 契约](docs/contracts/routes.md#p06-会话读取与-cookie-同步)。

## 监听器所有权与实时恢复

已认证外壳只为权威当前 `live`/`final` 场次建立单拍卖订阅；`/status` 是静态说明，不额外建立订阅。
持久化游标、连续 sequence/version 与权威快照决定恢复；`refetch_required` 保留高水位和现有 socket，
不能用事件 payload 推导价格、领先者或代理权限（见[实时契约](docs/contracts/events.md)）。
普通竞价事件只失效相关已挂载资源，从首次通知起合并 100 毫秒，进行中的读取
先完成再补读未消费通知；生命周期、discovery 或缺口立即触发权威刷新。浏览器不因没有业务消息推断失联；
visibilitychange、popstate、socket 和回调随所属外壳卸载清理，游标不能因重建 owner 退回零。
实时订阅将权威用户 UUID 与目标共同作为资源依赖；同场换账号关闭旧握手并重新订阅，
已确认的拍卖游标仍由外壳持有，不退回零，也不因同身份正常重读反复重连。
页面可见性与分片睡眠复用共享层 `PageVisibility`/`sleep_while_visible`（Waker 登记语义见
[共享层](crates/auction-web-shared/README.md#命令与浏览器状态)）；外壳安装时注入恢复可见后的补偿刷新回调，
轮询和实时重连须等恢复可见后继续。
事实 FIFO 淘汰时只删除唯一关联身份，不逐条扫描全部 256 项缓存；重复、冲突、gap 和 refetch 语义不变。
同一世界权威快照重读期间保留最近已确认的实时目标；缺口后的后续健康页可恢复 Live，永久错误或重试耗尽的 Manual 不由迟到页覆盖。

## 依赖与首屏边界

HTTP/stream wire DTO 直接复用 `auction-contracts`，本地只持有查询、展示和交互状态；Gloo 在本 surface 显式启用
JSON/WebSocket，不能依赖 Admin 或合并构建补齐 feature。会话读取失败保留错误与重试入口，不能伪装匿名；
页头同样区分加载、读取失败和明确匿名；失败显示五语错误与重试，不显示匿名登录入口。
登录、注销及认证失效通过 `hv.public.session-revision` 仅广播随机修订，其他标签页据此重读会话；窗口聚焦及恢复可见时也重读。
随机修订与本地登录不预先清除身份，权威响应确认换号后才销毁旧宿主，同账号重登保留原未知命令及 ID。
竞价/代理确认与重试冻结原用户 UUID，标记、警告渠道及注销同样携带可选 `x-auction-expected-user-id`，由 HTTP 与本次 Cookie
身份核对，避免预检与提交之间换账号。401、`session_changed` 或本地显式注销先失效旧身份并卸载旧确认宿主。
登录 return 只接受单斜杠开头的站内路径。首屏 15 秒未就绪只提示慢加载，真实 panic 才显示失败。

浏览器只在已认证且当前拍卖为 `live`/`final` 时建立拍卖实时连接；预览、准备开拍、结算中或无当前场次均停用，
预览徽章显示“预览”。当前场次每 60 秒后台复核及恢复可见补读继续生效，确认进入竞价期后自动连接。
可见目录首次跨过本场 `opens_at` 时补读一次权威快照，不依赖预览期本就不存在的 Live 连接；隐藏页不为该提醒发请求，
返回可见沿用既有补读。服务器尚未开场时仍显示预览/准备开拍，不能根据浏览器时钟直接开放竞价。
“立即刷新”按钮先显示忙碌反馈，再执行整页重载；预览期仍可手动刷新，自动数据同步不重载页面。
