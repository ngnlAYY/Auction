# Public 前端设计约定

[docs/README.md](../../docs/README.md) · [crates/auction-web-public/README.md](README.md) · [crates/auction-web-shared/README.md](../auction-web-shared/README.md) · [crates/auction-web-admin/DESIGN.md](../auction-web-admin/DESIGN.md)

本页记录公开站点的界面与交互约定。Public 面向浏览者、竞买人与查看结果的卖家：首要任务是找到装备、看懂价格与截止时间、明确确认出价，并在网络恢复后重新取得权威状态。它不提供任何管理入口（凭据、Worker、审计、配置）。

## 职责划分

| 位置 | 拥有 |
| --- | --- |
| `crates/auction-web-public/src/surface/` | 页面、交互与命令宿主 |
| `crates/auction-web-public/src/api/` | 同源 HTTP、响应解码、实时连接与会话 |
| `crates/auction-web-public/assets/public.css` | 设备无关的组件样式（`@layer surface`） |
| `crates/auction-web-public/assets/desktop.css` | 桌面紧凑密度（`@layer desktop`，`width > 64rem`） |
| `crates/auction-web-public/assets/mobile.css` | 手机与触控布局（`@layer mobile`） |
| `crates/auction-web-public/i18n/` | 五种语言文案 |
| `auction-web-shared` | 设计 token、reset、通用组件与浏览器机制 |

Public 不导入 Admin 的页面、样式或 `admin-*` 选择器；共享层只提供通用机制，业务字段、列宽、竞价状态与文案留在本端。

## 视觉基底

- 默认深色、紧凑、以数据为主；颜色、字体栈、字号、间距、圆角、层级与触控尺寸全部引用共享 [crates/auction-web-shared/style/base.css](../auction-web-shared/style/base.css) 的 token，不使用 webfont。
- 主要 token：背景 `--color-bg #0e1116`、容器 `--color-surface #161b22`、抬升层 `--color-surface-raised #1d242e`、文字 `#e6ebf2`、次要文字 `#93a0b4`、品牌强调（金）`--color-accent #d9a441`、进行中 `--color-live #3fb96f`、危险 `--color-danger #e66262`、链接 `#6ea8fe`。
- 页头可切换浅色主题（`:root[data-theme="light"]` 只改写 token，布局与密度不变），偏好保存于 `hv.theme`。启动页因 CSP 不能运行内联脚本，静态骨架始终为深色，WASM 就绪后再应用主题。
- 对比度目标 WCAG AA：正文 4.5:1，控件边界与图形 3:1。表单控件边界用 `--color-border-control`，表格与卡片分隔线用低对比 `--color-border`，悬停与焦点切换为金色。
- 状态颜色必须同时配有文字，不能只靠颜色区分（如分组“稀有/融合”、轮次徽标、连接状态）。
- 金额、倒计时与统计数字使用等宽数字特性对齐。

## CSS 分层与断点

三个样式文件都以 `@layer foundation, surface, desktop, mobile;` 开头，与共享层同序，避免 head 中标签顺序不确定时互相覆盖。

| 条件 | 布局 |
| --- | --- |
| `screen and (width > 64rem)` | 桌面紧凑密度：页头与筛选控件使用 `--size-control-compact`（1.75rem）、小号字 |
| `screen and (max-width: 48rem)`，或 `max-width: 64rem` 且 `pointer: coarse` | 手机布局：一般触控目标 `--size-target`（2.75rem），分页控件采用 2rem 紧凑高度；编辑字段字号至少 16px 防止聚焦缩放 |
| `screen and (min-width: 80rem)` | 账户页出价与代理列表并排（2:3） |
| `print` | 隐藏导航与交互控件，保留规则、黑名单与补偿等内容 |

断点切换只由 CSS 完成。[crates/auction-web-public/src/surface/presentation/desktop.rs](src/surface/presentation/desktop.rs) 与 [crates/auction-web-public/src/surface/presentation/mobile.rs](src/surface/presentation/mobile.rs) 提供两端各自的导航与筛选控件，用 CSS 隐藏非当前设备的那一份；业务表格、表单草稿、会话与世界选择、数据读取与命令宿主只有一份，调整窗口不会重新挂载、重新请求或丢失已确认/进行中/结果未知的命令。

## 外壳

```text
品牌 │ 场次状态 · 期号 / 世界 · 剩余时间      连接状态 + 刷新 │ 世界 · 语言 · 主题 │ 会话
──────────────────────────────────────────────────────────────────────────────
侧栏导航 │ 筛选与上下文 → 目录 / 详情 / 账户 / 内容 → 分页与操作反馈
```

- 当前导航项带可见标记与 `aria-current`；世界与身份始终可辨认，避免在不清楚当前世界或账号时出价。
- 品牌常驻顶栏左端，侧栏只放导航与收起按钮；侧栏展开时分组标题、导航标签与收起按钮文字放不下则单行省略，完整文字保留在 `title`。
- 顶栏右侧分三组并以细分隔线隔开：连接状态与整页刷新、世界/语言/主题切换、会话入口。连接状态只用圆点加文字（视口不超过 75rem 时只留圆点，文字仍是可访问名称与 `title`）；刷新是常驻的方形图标按钮，任何连接状态、登录与否都可用。未登录时会话组只有一个“登录”按钮，已登录是头像下拉。右侧各组不收缩，空间不足时由左侧场次信息先省略。
- 手机顶栏两行：第一行是菜单按钮、品牌、连接状态圆点、刷新与会话入口（已登录只显示头像），第二行是场次状态、期号/世界与倒计时。世界、语言与主题切换随导航菜单一起展开（三等分一行），收起时不占位。主导航折叠为菜单（`aria-expanded`，Escape 收起并把焦点还给入口）。
- 正文占满可用宽度，左右留白并避让安全区；规则正文整体限制在约 70ch 阅读宽度：二级标题带分隔线、三级标题用强调色，列表符号为强调色，行内代码带底色；表格按内容宽度排布（不超过正文宽度），单元格可折行、带表头底色与斑马纹。排版只作用于 Public 规则页，不改共享 Markdown 组件。服务说明段落同样限制约 70ch。

## 目录与表格

- 当前拍卖目录先按“装备分组：全部/稀有/融合”，再按“装备类型：全部/七类装备”筛选；同行提供“等级上限”与“显示无等级装备”。筛选条件写入 URL（`equipment_group`、`type`、`max_level`、`include_unleveled`，默认值省略），变化时回到第 1 页。统计与过滤都由服务端完成，前端不根据本页数据推断全局结果。
- 类型工具栏右端是列设置的图标按钮（可访问名称“列设置”）：点击后在按钮下方展开下拉面板，自上而下是标题、“全选”与当前布局的逐列复选框，勾选立即生效；点面板外或按 Escape 关闭并把焦点还给按钮。“全选”在全部列可见时为选中，只有部分列可见时为混合态；取消全选只保留装备列。偏好保存在 `hv.public.catalog-columns.v1`；隐藏后按剩余列的原权重归一化到 100%，至少保留一列（最后一列的复选框禁用）。列显隐不改变 URL、请求或命令状态——隐藏操作列不会卸载命令宿主。
- 桌面表格保持 100% 容器宽度与按列的百分比宽度；手机把同一行重排为卡片，字段标签来自五语 `data-label`，原生表头视觉隐藏但仍供辅助技术读取。不使用横向滚动或固定最小宽度。
- 桌面长名称使用截断与完整值提示，手机卡片允许名称、时间与金额折行；装备链接只使用后端提供的安全字段，空链接不伪造入口。
- 金额与计数列使用正文字体的等宽数字并右对齐（目录、往期拍卖、出价记录、详情竞价历史、补偿池）；拍品编号保留等宽字体以区分代码。
- 只有少量短字段的表格（如详情页装备属性）在手机上保持表格，不写 `data-label`，从而不进入通用卡片布局。只有一页时不显示分页器。
- 展开/折叠控件统一使用纯 CSS 箭头 `public-chevron`（折叠向右、展开向下）。
- **筛选面板**：装备分组/等级与装备类型两条工具栏合并为一张面板（目录尚未渲染时只有前者，保持完整卡片）。手机上两条工具栏套用同一套三列网格——标签列、控件列、列设置按钮列：分组、等级上限与类型的标签对齐成一列，分组与等级的控件等宽等高，类型选择器右侧留给列设置按钮；“显示无等级装备”独占一行，等级输入的错误提示紧跟输入行。
- **行状态**：“已标记”与“领先”是两种独立状态，可以同时出现。已标记的拍品在行首显示左缘色条（落在第一个可见列上，隐藏编号列后仍贴着行的左缘）；当前账号领先的拍品整行使用领先底色。悬停与键盘聚焦只加深领先底色、不改变色条，两种状态都不会被普通悬停底色盖掉。手机卡片里色条贴着卡片左缘，领先是整张卡片的底色。账户出价历史、出价记录与拍品详情页的领先行只用底色表达，同样在悬停时保留。
- **操作列**：预览、竞价与已结算三种目录布局都有操作列，固定三个槽位——查看、出价（匿名时是登录链接）、标记，顺序不随资格变化。桌面是 24px 图标按钮，`aria-label` 带拍品编号，`title` 给出短名称；手机卡片里是等宽的带边框按钮并达到触控命中高度。出价与标记只出现在竞价中的拍品上，预览与已结算表只有查看入口；不可出价的原因说明另起一行，不挤占槽位。
- **拍品详情抽屉**：点击目录行、聚焦行后按 Enter/Space 或点查看按钮，都从右侧滑出同一个详情抽屉，不离开目录页、不写 URL。行内自带交互的区域（装备链接、操作栏、可展开的截断文本）保持各自行为，正在选择文本时点击不打开抽屉。抽屉展示所选行的实时投影（当前价、领先者、下一口价、剩余时间随目录刷新）、装备属性（默认 6 条，“显示全部（N）”展开）与最近 4 条出价；“查看全部（N）”打开分页的完整竞价历史弹窗。预览中的拍品不读取出价记录。底部依次是出价入口、标记、历史成交价与游戏内查看链接；“历史成交价”打开分页弹窗，列出当前世界往期拍卖中同名装备的成交期数、等级、成交价与成交时间。它复用价格历史接口的名称词条匹配（各词都包含，不是精确等于），名称不同的行会标出实际装备名。出价入口的三态（命令按钮及其禁用原因、登录链接、不提供）由该行操作栏按同一套资格判定写入，抽屉不重算资格；所选行离开目录（翻页、筛选或目录读取失败）时入口失效关闭，不保留过期的出价能力。关闭按钮、遮罩点击与 Escape 关闭抽屉。
- **目录之外的查看入口**：账户页“出价历史”与出价记录页的拍品编号是纯文本，不再跳转到拍品详情页；两张表都有装备名称列和只含“查看”按钮的操作列。按钮先按拍品读取详情，就绪后打开同一个详情抽屉（只读：不带出价与标记入口，出价资格仍只在拍卖目录里判定），读取期间按钮标记为忙碌，失败在表格下方提示。抽屉内的历史成交价按拍品所在世界查询：出价记录页使用页面的世界筛选，账户页只有拍卖 UUID，打开弹窗时按拍卖读取其世界，读取失败则提示不可用而不猜测世界。
- **内容页外观**：出价记录、往期拍卖、成交价格、补偿池、黑名单、论坛、账户与拍品详情页的卡片使用与拍卖目录相同的圆角与投影；铺满卡片的列表带表头底色带，桌面使用与目录相同的小号字与行高，悬停行有底色。出价记录页的世界/场次选择与本场摘要、拍品筛选合并为一张筛选面板。
- 装备属性表等小表格不进入卡片布局；表格列比例与单元格提示来自共享 `TableColumns`。分页器由 `PublicPager` 注入 Public 文案与 10/20/50/100 预设，`max_offset` 决定可导航上限（默认 10,000，黑名单单独注入），补偿流水使用独立偏好。
- 内容页不显示页面标题与简介：页面名称由导航高亮项表达，正文从筛选或数据开始；页面名称只作为主区域的 `aria-label`（规则页用文档标题）。登录页的表单标题与拍品详情页的拍品编号不是页面名称，照常显示。补偿池的一句话说明放在“计算方式”卡片里公式之前。空列表使用虚线卡片提示，不渲染只显示“共 0 条”的分页器。
- 不渲染视觉隐藏的节点：区域与表格的名称用元素自身的 `aria-label`，只靠颜色表达的行状态（领先、当前有效出价）与输入提示用 `aria-description`。与可见内容或顶栏重复的隐藏副本一律不保留。
- 加载提示只在顶栏：任何页面的读取在当前查询还没有可展示结果时，经 `use_content_loading` 登记到外壳，顶栏上下文位置显示同一个加载提示；正文不插入“加载中”占位块，避免占位块撑开又收回容器。同查询的后台重读保留旧结果、不提示；读取失败是带重试的最终状态，不算加载。弹窗内的读取与表单的“保存中”反馈留在各自位置。

## 补偿池

- 页首是简短说明，下面并排两张卡片：当前余额（强调色）和三条计算规则；手机上余额在前。
- 本页金额一律显示精确值加 `c`（如 `48,000c`），不缩写为 K/M，同一列单位一致，便于复算。税收与补偿按池的视角带符号与颜色（流入 `+`、流出 `−`），数字列右对齐。
- 逐件明细沿用线上原版的“类型 + 金额”：一件成交要么缴纳税收、要么获得补偿，“类型”列以小标签标出，“金额”列给出带符号的数额，名义折扣需求见补偿金额的提示。其余列为拍品、装备、装备世界、持有比例、调整比例、总时间、成交价、买家实付、卖家所得；买家与卖家不单独成列，以 `金额 (玩家名)` 附在买家实付与卖家所得格内，金额始终完整，名字过长时截断并提供完整值提示，没有投稿记录的卖家（`—`）不显示括号。
- 冲正列默认隐藏：批次表只在本页有冲正时显示，逐件明细只在本页有已撤销成交（含未冲正）时显示；批次单元格只显示冲正净额，笔数见提示。
- 表头允许折行；逐件明细只截断装备名（单行，完整名称见提示），其余列宽按窄桌面下最长完整值实测预留（含英文 “Compensation” 标签）。窄桌面（64–90rem）收紧字号与留白，保证千万级金额与结算时间完整显示。

## 分页

所有主列表（目录、往期拍卖、出价日志、详情竞价历史、成交历史、黑名单、补偿池）共用共享分页器：前后按钮与有界页码窗口、总数、每页数量（预设 10/20/50/100 与自定义正整数）、跳页。页码与 `page_size` 写入 URL，URL 显式值优先；用户主动修改的每页数量保存到 `hv.public.page-size`。补偿池展开的逐件明细独立使用 `movement_page`、`movement_page_size` 与 `hv.public.movement-page-size`。没有权威总数时不伪造总数。`PublicPager` 的 `show_size_picker = false` 保留经典上一页/下一页布局（账号页与装备属性表），`hide_when_single` 在只有一页时隐藏控件但仍保留挂载，让页码与 URL 继续收敛；`max_offset` 覆盖端点 offset 上限（默认 10,000）。

手机分页只保留当前页与相邻页、前后按钮、总数与每页数量选择；自定义数量与跳页表单由 CSS 隐藏。分页响应必须与当前请求身份匹配后才参与展示及页码纠偏，不能用旧查询的总数修改新 URL。同查询后台刷新可保留已完成快照；详情读取与命令宿主按 lot UUID 隔离，切换目标时销毁旧宿主。

## 成交历史

- 页面顶部是独立的全宽搜索区；没有已提交的筛选时不加载结果。分组标题占满整行，名称按可用宽度截断。
- 名称筛选按空白或英文逗号拆分，所有片段按字面包含匹配（最多 8 个词）；买家/卖家按完整玩家名精确匹配，不区分大小写。
- 金额输入支持 C/K/M 单位；非法值保留原文供修正并阻止请求。
- `history_sort` 对完整结果排序（默认时间降序）；`history_group` 只改变本页的分组展示（逐条/装备名/买家/卖家），不触发新的查询。统计中位数优先使用服务端的精确值。

## 竞价、代理与标记

- **出价**：弹窗以“直接出价 / 代理出价”切换，两个表单共用同一拍品摘要与命令宿主。直接出价输入以 K（1000 credits）为单位的纯数字，默认值为下一口价向上取整，上限为 `MAX_PUBLIC_BID_AMOUNT`。首次提交先冻结金额与 `command_id` 并进入确认视图：紧凑拍品行、出价类型、出价金额与约束性命令说明；确认视图的关闭、Escape 或“返回修改”回到编辑态，确认后才发送。打开弹窗时焦点在金额输入框，进入确认视图后焦点落在“确认出价”按钮，“返回修改”回到金额输入框；长按 Enter 产生的重复按键不会越过确认步骤。
- **出价结果**：直接出价成功后弹窗关闭，结果由页面右下角的提示条回显——领先时给出当前价，未领先时说明出价已接受并附当前价——约 5 秒后自行消失，同一时刻只保留最近一条。提示条只是已提交结果的回显，不保存命令状态；目录行与抽屉随后从权威投影刷新。失败或结果未知时弹窗保持打开，按下文的重试规则处理。代理命令成功后仍在弹窗内显示结果面板，由用户关闭。
- **代理**：在同一弹窗的代理 tab 或详情页代理入口创建；创建时选择上限（无后缀或 K 表示整数千，M/B 分别允许最多三/六位小数，所以手机保留字母键盘）与 Fast/Slow 模式；服务端不允许 Slow 时该选项禁用并说明原因。已有代理只能降低上限，下限由服务端投影给出（等待中的代理以下一口价为下限，否则以当前价为下限）。代理命令的确认视图与直接出价同款，类型行标明代理模式或“降低上限”，焦点规则也相同：进入确认视图后落在确认按钮，“返回修改”回到上限输入框。代理表单打开期间，竞价事件触发的授权刷新沿用上一次读取的结果直到新结果到达，不会清空已输入的上限、模式或焦点。
- **标记**：整场标记集合一次读取，所有行共用，不逐行请求。按钮直接提交带 `expected_version` 的切换命令，不进入竞价确认弹窗；页面级用户宿主保留原 `command_id` 与完整负载，结果未知时只允许原样重试。
- **两阶段确认与重试**：出价与代理命令通过共享 `ConfirmCommand` 状态机执行“准备 → 确认 → 提交”。同一输入重试复用同一 `command_id`；网络结果不确定时保持“结果未知”，只允许原样重试或显式放弃，不会生成新命令。提交中弹窗禁止通过 Escape 或关闭按钮退出；遮罩点击始终不关闭。
- 匿名用户看到的是“登录后出价/登录后标记”链接，带安全的 `return_to` 回到原位置。
- 竞价状态、领先关系、代理能力与禁止原因全部来自服务端投影，前端不复制竞价或代理状态机。

## 实时与刷新

登录用户的看板与 lot 详情通过 WebSocket 接收事件，断线后按指数退避（1 秒起步、30 秒封顶、带抖动）重连并用事件回放补齐；连续快速失败或未登录时进入手动刷新模式。页面隐藏时暂停轮询与重连退避，已有连接仍可接收事件。普通竞价事件对相关资源做 100ms 合并的有界重读，生命周期变化或回放缺口刷新权威快照。外壳另按可见时间每 10 秒读取 readiness、每 60 秒刷新权威数据，恢复可见时立即补读。页头的整页刷新按钮常驻：它重新加载页面，同时清掉内存读缓存并重建实时连接，匿名访客与实时已连接的用户同样可用。

## 会话

会话 Cookie 为 HttpOnly，由后端签发。跨标签页通过 `localStorage` 的 `hv.public.session-revision` 广播随机修订并触发权威身份重读，不在该键保存身份或凭据。登录、退出、登录时长偏好保存/重放及 Cookie 持久期同步共用 Web Lock `hv.public.session-cookie`；缺少原生 Web Locks 或获取超时时明确拒绝写入。普通 GET 只读取会话；需要同步浏览器持久期时，先持锁重读当前身份，再显式 PUT 同步，并持锁至完整响应或超时取消收口。暂时重读失败保留已确认身份的命令宿主，但禁止新写入；确认身份变化后销毁旧宿主。账户页提供登录时长与竞价提醒渠道两项偏好。

## 无障碍

- 所有交互使用原生元素（按钮、链接、select、fieldset/legend、label），DOM 顺序与键盘顺序和视觉顺序一致。
- 错误提示通过 `aria-describedby` 关联到对应输入；弹窗与浮层可用 Escape 关闭并恢复入口焦点。
- 目录行可用 Tab 聚焦，焦点环画在行内侧（滚动容器会裁掉外侧描边）；Enter/Space 只在焦点位于行本身时打开抽屉，行内控件的按键不受影响。
- 详情抽屉是模态对话框：打开时焦点落在关闭按钮，关闭后回到打开它的行或查看按钮；从抽屉再打开出价、竞价历史或历史成交价弹窗，关闭后焦点回到抽屉内对应的按钮。
- 出价结果提示条是常驻的 `role="status"` 礼貌播报区域，不抢焦点、不拦截指针；抽屉打开时它避开抽屉底部的操作区。
- 尊重 `prefers-reduced-motion`；`hover` 效果只在 `(hover: hover)` 设备上启用。
