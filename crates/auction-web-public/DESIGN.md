# Public 公开端设计

[系统设计](docs/design/architecture.md) · [模块说明](crates/auction-web-public/README.md) · [文档导航](docs/README.md) · [独立的 Admin 设计](crates/auction-web-admin/DESIGN.md)

本页描述现有 Public 界面设计与交互约定；源码、内嵌产物与线上页面可能版本不同，验收边界见[状态页](docs/status.md)。

## 1. 定位与隔离

公开端服务浏览者、竞买人及查看寄售结果的卖家：首要任务是找到装备、理解价格与截止时间、明确确认出价，并在网络恢复
后重新取得权威状态。它不是管理控制台，不展示凭据管理、Worker 操作、审计编辑或运行配置入口。

页面与交互由 [src/app/](crates/auction-web-public/src/app/) 拥有，API/实时恢复由 [src/api/](crates/auction-web-public/src/api/)
拥有；[public.css](crates/auction-web-public/assets/public.css) 拥有设备无关样式，[desktop.css](crates/auction-web-public/assets/desktop.css)
与 [mobile.css](crates/auction-web-public/assets/mobile.css) 分别拥有桌面密度和手机/触控布局，文案为 [i18n/](crates/auction-web-public/i18n/)。
Public 不导入 Admin 页面/资源；共享层只提供通用机制，业务字段、列宽、竞价状态和文案留在本端。

## 2. 信息架构

| 页面族 | 入口示例 | 核心内容 |
| --- | --- | --- |
| 当前拍卖 | `/` | 世界、当前/预览/历史视图、场次摘要、分类筛选和拍品目录 |
| 拍卖历史 | `/auctions` | 世界与状态筛选、分页、拍品、出价记录及已发布论坛主题入口 |
| 装备详情 | `/lots/{lot_id}` | 装备安全投影、价格、截止时间、竞价历史和本人代理状态 |
| 竞价记录 | `/bidlog` | 活动／已结算场次与拍品筛选、玩家、来源及持久化竞价事实 |
| 成交历史 | `/history` | 装备、日期、价格、买卖方筛选及成交统计 |
| 论坛同步 | `/forum` | 只读同步开关、同步摘要、主题链接、真实处理楼层及更新时间 |
| 公开内容 | `/rules`、`/blacklist`、`/compensation-pool` | 已发布规则、禁拍名单与补偿流水 |
| 登录与账户 | `/login`、`/me` | Public Key 登录、账号竞价警告渠道、当期标记装备、本人竞价及代理授权 |
| 服务说明 | `/status` | 静态产品说明，不另建实时连接 |

## 3. 外壳与布局

```text
品牌 / 主导航                         世界 / 连接状态 / 刷新 / 语言 / 账户
─────────────────────────────────────────────────────────────────────
页面标题或拍卖摘要 → 筛选与上下文 → 拍品表、详情、账户或内容文档 → 分页与操作反馈
```

`public-shell` 持有页头，品牌用强调色，当前导航项带可见标记与 `aria-current`；世界选择与账户状态须可辨认，
不让用户在不清楚当前世界或身份时提交竞价。窄屏主导航折叠为两列菜单并用 `aria-expanded` 表达，开关显示为 44px
方形“☰／✕”图标，按钮文字仍是可访问名称，生成图标以空替代文本对读屏隐藏。连接状态与刷新、会话链接与按钮分别组成整体，
容器内两项等宽各占一半：状态保留圆角胶囊框，刷新、“我的出价”、退出为描边按钮，登录为强调描边；未渲染刷新时状态独占整宽，
加载与错误提示另起整行，用户名在半栏内单行省略。手机按 DOM 顺序排成三行：品牌与导航开关、世界／语言各半、
连接整体／会话整体各半，最小内容放不下时整组换行。桌面页头控件统一为共享 `--size-control-compact`（28px）高度和小号字，
触控断点恢复 44px。
所有公开页正文及启动占位占满可用宽度，左右各留 12px，遇系统安全区取较大值，筛选和控件可换行。
规则、论坛及登录页不设独立页面宽度上限；规则正文仍使用 `public-rules-page` 与安全 Markdown 块，正文与服务说明的段落、
列表、引用和标题另限制为 70ch 阅读行宽并靠左（约 75–80 个拉丁字符或 35–40 个汉字），表格与代码块仍占满容器。论坛状态文字靠左、“查看论坛帖子”位于同一状态行右侧、空间不足自然换行，
下方只保留处理楼层、更新时间及简短延迟提醒（正文、版本与诊断详情归 Admin）。黑名单页保留标题、名单或空态与分页，
仍显示 MoogleMail 玩家名称，不回退为内部数据库 ID。

`width <= 48rem` 或 `width <= 64rem` 且 `pointer: coarse` 使用手机布局，其他屏幕使用桌面展示；桌面紧凑密度在
`width > 64rem` 启用。手机筛选和会话按可用宽度换行，竞价记录/往期拍卖的选择器允许收缩，避免长本地化选项撑大页面。
详情事实栏在手机按字段显示卡片，分组与标记占满整行，分类、等级和平均 Roll 分两列；无需横向查看。页头、正文及启动占位避让安全区，
页面使用动态视口高度并保留缩放；共享弹窗跟随键盘缩小后的可见视口，内容可滚动，保留标题与关闭入口。
触控动作至少 44px 高，输入字号至少 16px；例外是单行分页器（32px）与目录分组/类型筛选栏（36px），二者输入字号仍为 16px。普通出价使用整数数字键盘，代理上限保留 K/M 字母输入，登录与历史搜索提供回车提示。

[presentation/desktop.rs](crates/auction-web-public/src/app/surface/presentation/desktop.rs) 拥有桌面导航、类型标签和账户章节入口；
[presentation/mobile.rs](crates/auction-web-public/src/app/surface/presentation/mobile.rs) 拥有手机折叠菜单、原生装备分组/类型选择器、
账户章节折叠入口及高级历史筛选底部提交按钮。两端只消费投影和事件，导航目标由同目录 `mod.rs` 统一维护，
手机菜单支持 Escape 收起并恢复入口焦点。CSS 隐藏非当前设备控制，隐藏项不占布局或键盘顺序，交互 ID 不重复。
业务表、表单草稿、会话/世界选择器、读取资源和命令宿主只有一份，不按宽度重新挂载、重新请求或改变业务 key；
调整窗口不会清除已确认、进行中或未知结果意图。打印隐藏两端导航，保留共享内容。

账户页使用同页章节锚点跳转到渠道、登录时长、标记、出价及代理；手机保留原生折叠入口，不复制偏好表单。
渠道、登录时长、当期标记、出价及代理五个顶层分区使用同一卡片外观（边框、底色、内距一致），标题统一位于卡片内，
fieldset 只保留分组语义；同卡片内的多个世界以分隔线区分，表格不再叠加第二层边框。渠道和登录时长由稳定容器承载，
`width > 64rem` 时按 2:3 并排；出价与代理列表在 `width >= 80rem` 时同样按 2:3 并排，两行列边缘对齐、同行卡片等高，
卡片间距由 `--account-gap` 统一（手机 12px、桌面 16px），各表仍占所属容器 100%，列权重不变。桌面偏好选项与按钮使用
共享 28px 紧凑高度。更窄屏幕按原顺序纵排，手机记录卡片压缩字段与段落留白，偏好选项
保留两列、44px 按钮和至少 16px 输入字号。账户列表仅在超过一页时显示分页；已挂载的 Pager 仅隐藏控件，
仍可在总数减少后纠偏页码和 URL。布局和隐藏容器不改变账号 key、偏好草稿、确认、提交门禁或独立分页。

## 4. 视觉基底

沿用深色、紧凑、以数据为主的界面，不增加外部字体或主题框架：背景/容器层级、主次文字、金色品牌强调、蓝色链接、
语义状态及系统字体均使用[共享 base.css](crates/auction-web-shared/style/base.css)变量，状态颜色须配明确文字。
三个 Public CSS 作为独立静态 Asset，均先声明 `@layer foundation, surface, desktop, mobile;`；
设备无关规则写入 `surface`，桌面规则写入 `desktop`，手机/触控规则写入 `mobile`。共享基底使用同一层序，
避免 Dioxus head 标签顺序不确定时覆盖触控尺寸；不使用本地 CSS `@import` 或新增打包链。
`public-*` 组件选择器仍由本端维护，不引入 `admin-*` 选择器；设备规则使用 screen media，打印规则留在设备无关层。
标题、段落和长字段沿用共享折行规则；金额、倒计时及统计数字使用等宽数字特性建立对齐，不增加字体下载。
键盘焦点和触控反馈由共享层提供，Public 保留自身组件的颜色与布局层级。
输入框、选择器及分页输入使用共享 `--color-border-control` 边界（对三层底色不低于 3:1），表格与卡片分隔线保持
低对比 `--color-border`，悬停与焦点仍切换为金色；错误文字使用在 raised 底上不低于 4.5:1 的 `--color-danger`。

## 5. 表格与信息密度

表格遵守[布局契约](docs/design/table-layouts.md)：桌面与打印保留 100% 容器宽、独立百分比列宽；手机业务表将同一行 DOM
重排为卡片，短字段分两列，名称和操作占满整行。可见字段标签复用五语 `data-label`，原生表头视觉隐藏但仍供辅助技术读取，
caption、行列关系及用户列偏好保留。长名称、时间与金额自然折行，完整值提示和原生链接保持可用；Markdown 仍为表格，不增加横向滚动或固定最小宽度。装备链接只消费安全 DTO，空链接不伪造入口。

装备目录的筛选顺序固定为“装备分组：全部／稀有／融合”在上、“装备类型：全部／七类装备”在下。
两个筛选栏独立命名；分组和桌面类型用原生按钮与 `aria-current` 表达当前视图，手机类型用原生带 label 的 select，
选项仍为“全部／七类装备”及同一权威计数。两端共享 URL 更新回调，DOM 和键盘顺序与可见布局一致。
默认分组为全部，可与类型组合；任一筛选变化回第一页，数量保持不变，`equipment_group=rare|fusion` 随 URL 恢复，
省略表示全部，非法分组退回全部。服务器先按分组及等级条件统计类型数量，再按类型和分页返回；浏览器不对本页数据推断全局筛选结果。
列表装备列仅显示装备名称，随后依次为独立的“分组”列和“平均 Roll”列，分组以纯文字显示稀有／融合；
详情保留“装备分组”事实，稀有使用强调色，融合使用中性色，分组始终有可读文字。
装备名保持既有链接样式，论坛帖子仍由论坛渲染器上色。当前、预览及历史某场目录共用这套展示。
筛选无结果时保留两行筛选并显示匹配条件的空态；预览摘要与详情分组必须一致，更新目录的上下文也包含分组条件。

装备分组同行提供“等级上限”数字键盘输入，旁边为原生“显示无等级装备”复选框（默认勾选）。
上限留空表示不限，非空接受 `0..=i64::MAX` 的 ASCII 十进制整数；高于上限隐藏，等于上限保留。
无数字等级不解释为零级；复选框独立生效，取消后即使上限留空也隐藏这类装备。
上限在回车或离开输入框时提交，不保留独立“应用”按钮；复选框变化应用当前有效草稿。输入清错，非法输入不替换已应用查询。
分组/等级表单在加载和错误分支之外保持挂载，后台刷新不覆盖同查询草稿；URL 非法值保留为可修正错误并阻止目录请求。
`max_level` 和 `include_unleveled=false` 写入 URL，默认值省略，浏览器前进/后退恢复；不新增本地持久化偏好。
条件变化回第一页并保留类型及数量，异步快照身份包括两项等级条件；空结果仍保留筛选入口。
桌面等级框宽 5rem、最小高 1.75rem，上下内边距为 0、左右为 4px；等级与无等级标签同为共享 28px 紧凑行高，
分组/等级行与类型行的底部间距均为 8px，`desktop.css` 显式清零工具栏内筛选导航的通用 12px 底边距；窄屏允许分组和等级控件自然换行，
触控或 48rem 以下仍保留 44px 输入高度与至少 16px 字号，原生 label、焦点及错误关联保留。
这些条件只影响目录读取，不修改装备等级、详情可访问性、标记集合或竞价权限；账户完整标记读取显式使用不限制的默认条件。

装备类型行右侧提供“显示列”按钮，展开内联复选框面板；类型筛选与按钮以两列网格固定在同一行，
桌面类型标签与右侧按钮共享 28px 紧凑首行高度、垂直居中对齐，按钮为小字号、小圆角矩形，左侧选项可内部折行；
手机装备分组与类型均改为原生选择器（分组由 `presentation/mobile.rs` 提供，与桌面标签共用当前值和回调），标签与选择框同排，
右侧“显示列”按钮与类型选择器垂直居中且仍在同一行；分组、等级、类型三行控件为 36px。实时、已结算与预览目录均默认全部显示。
面板采用紧凑布局：“显示全部”和关闭操作与标题同行，DOM/键盘顺序与视觉一致；内边距上下 8px、左右 12px，
标题、选项与按钮均用共享小号字，选项按内容宽度顺排（列间距 16px），宽屏通常一行放下，小容器允许文字折行而不产生横向滚动。
桌面选项及按钮使用共享 `--size-control-compact`（28px）高度，手机与触控横屏由该变量恢复 44px 点击高度。
选择立即生效，`surface/catalog/columns/` 统一拥有列身份、默认权重、键盘交互及
`hv.public.catalog-columns.v1` 浏览器偏好。列名复用各布局的五语表头，起拍价和当前价共用价格列偏好；
预览不提供下一口或操作选项，已结算不提供操作选项。隐藏后按可见列的原权重重新归一化到 100%，不改变列顺序。
至少保留一列；若已有选择在切换后的布局没有可见列，临时显示装备列，不覆盖原偏好。面板可恢复全部列，
Escape 或关闭按钮收起后返回入口焦点。存储缺失、损坏或被禁止时退回默认；写入失败不撤销当前选择。
列显隐不修改 URL、筛选、分页或请求范围，不保存业务数据；隐藏操作列保留命令宿主及冻结状态，
隐藏剩余时间则卸载该单元格的秒级订阅。全部公开页使用可用宽度与较小安全边距，规则、论坛、登录的容器也不再收窄，只有长文正文限制阅读行宽。

首页装备目录（含历史目录）、往期拍卖、出价记录、装备详情竞价历史、历史成交价、黑名单、补偿池批次与展开流水统一使用
「前后按钮及数字页码 → 总数 → 每页数量 → 跳页」控件：默认 10 条并保留 10/20/50/100 预设与自定义输入，取消 200 条业务
上限，只接受 `i64` 可表示的正整数（空值、0、符号、小数、科学计数法、空白及溢出都不提交），提示位于自定义输入下方
左对齐并关联可访问描述。数量原样交给后端，不截断成预设值。数字页码显示首尾与当前页附近的有界窗口，其余用不可点击
省略号；无权威总数时不伪造总数。改变数量回到第 1 页并保留筛选，`page_size` 与页码写入 URL 支持刷新、分享和前进/后退；
URL 明确数量优先，非法数量回退 10，未提供时读取本地偏好。用户主动确认才保存 `localStorage` 的 `hv.public.page-size`
（全部主列表共享），访问链接不覆盖偏好，存储损坏退回 10；外壳首页入口只保留世界参数并在点击时恢复最新偏好。补偿池
展开场次使用 `auction`，流水独立使用 `movement_page`/`movement_page_size` 与 `hv.public.movement-page-size`，改变批次
分页收起流水；偏好读写由 `surface/pagination/preferences.rs` 拥有。原生 select、可见焦点与 `aria-current=page` 保留。

分页与 Admin 共用共享层的样式，整体右对齐，桌面使用 28px 紧凑控件，折行后各行仍靠右。手机与 PC 一样单行显示
‹ 当前页及前后各一页 › · 总数 · 每页数量，控件 32px；自定义数量与跳页只在 PC 提供，细节见[共享组件](crates/auction-web-shared/README.md)。
DOM 顺序与键盘顺序一致，草稿不因断点切换重置。

补偿流水只展示真实税收与补偿条目，期初/期末账本占位行不显示；整期的「期初 + 税收 = 补偿支出 + 期末」
结算等式放在每页表格固定末行，以跨八列的单元格展示。等式读取整期权威汇总，分页不重新求和；桌面保留单行，手机可折行。
补偿批次与展开流水各自显示卡片，嵌套字段标签互不混入；完整文本提示、HTTP 账本事实、分页计数与游标保持原语义。
当前流水页只有期初／期末占位而无可见记录时，手机仍保留卡片布局的汇总末行与可访问表头。

浏览器表达意图，不计算最终竞价结果，也不复刻领域状态机：选择拍品 → 读取权威状态/资格 → 输入金额 → 明确确认 →
冻结 `command_id` 与负载 → 提交 → 展示结果 → 重读权威快照。

- 普通出价输入为不带后缀的 K 单位整数，发送前显示实际 Credits 金额和独立确认步骤。

已知世界的详情链接保留 world；裸链接及冲突 query 以实际 auction 查询结果设置实时房间，
等待或失败时不继续使用 Main 默认目标，迟到结果按 Lot/Auction 请求身份丢弃。

### 6.2 登录时长

「我的」在 `#login-duration` 提供永久（默认）与自定义时长，使用原生 radio、数字输入及分钟/小时/天选择器。
输入精确换算为整分钟，接受 1 分钟至 365 天；不静默取整。权威偏好读取完成前禁保存，字段错误保留可编辑草稿，
提交中锁定控件；未知结果只能原样重试，409 明确要求重读，不用新版本覆盖未确认命令。
账号默认时长与当前会话实际截止分别展示：保存从服务器时间起应用当前会话，并影响后续登录，不改变其他设备现有期限。
旧会话保持既有截止，永久仍受退出、换 Key、账号限制、撤销和浏览器 Cookie 清理/期限约束。
组件按账号 UUID 隔离；保存成功重读最新偏好和会话，有限期限到期后权威复核，永久不创建到期计时器。
布局复用账号设置样式，窄屏字段与动作换行，触控输入至少 16px；五语文案与错误提示同步。
会话 GET 不再续写或清除 Cookie。登录、退出、偏好保存及空正文 PUT 同步共用原生 Web Lock，并在锁内重新读取身份；
锁从发送前一直持有到完整响应或取消收口，不把先前身份的迟到 Cookie 写入下一次登录。
新请求在不支持 Web Locks 或等待超时时明确失败；既有未知结果不因此解除。使用边界、续期和同版升级见
[P06 契约](docs/contracts/routes.md#p06-会话读取与-cookie-同步)。

## 7. 数据、时间与实时状态

初次读取、刷新、空结果、失败与能力缺失是不同状态，网络错误不能冒充匿名或空表；筛选和分页由页面 owner 与 URL 双向
同步。倒计时使用服务端时间校准、仅作显示，拍卖截止、最终阶段和资格由后端决定。WebSocket 是已提交事件的通知入口，
不承担竞价写入，sequence 与实体 version 不能混用；跳号、重连或服务端要求重新读取时通过 HTTP Catch-up 与权威快照恢复。
页头连接徽章统一播报连接状态，正常静默不等于断线。`501 feature_not_supported` 属于档位限制，不提供无意义重试；
`rules_unavailable` 需要发布正式正文，不能用示例正文伪装（见[事件契约](docs/contracts/events.md)）。
查询切换与同查询后台刷新分开处理：成功、空结果和错误都绑定完整请求身份；竞价记录、往期拍卖、指定历史拍卖、
黑名单、补偿池、账户及 lot 竞价历史不得沿用其他查询的结果。规则正文和错误另绑定请求语言。
同一查询的已完成快照可在后台重读期间保留；旧结果不能驱动新查询的分页纠偏。装备详情以 lot UUID 隔离读取与命令宿主，
站内切换详情时不沿用上一标的的资源或确认状态。

出价记录与 lot 竞价历史完整保留已接受的普通报价和代理回应；来源标记明确区分普通/代理，
论坛来源继续使用真实楼层和链接。两处表格保留原列宽、行结构与稳定 bid ID，原生 caption 仅供屏幕阅读器读取竞价日志标题，不展示额外说明句。
同一时刻仍按服务端版本和 fact_index 倒序，不在客户端重排、合并或补造触发关系；原逐条分页不强制把同事务两行放在同页。
`valid` 只表示当前领先；视觉强调与辅助文本对应“当前领先／当前未领先”，不是接受／拒绝判定，代理上限始终不展示。

浏览器仅在已登录且权威当前场次为 `live` 或 `final` 时建立拍卖 WebSocket。预览、开拍准备、结算中或没有场次时
不建立拍卖或发现流连接；预览徽章显示既有本地化“预览”，其他停用场次显示空闲，读取失败独立显示降级。
可见页面每 60 秒读取当前场次，恢复可见时补读，确认开拍后自动建立实时连接，确认离开竞价期后关闭；
同一世界的短暂后台读取保留最近确认目标，换身份或世界仍先隔离旧目标。服务端发现流、游标与实时四态契约保持原义。
同场换账号也重新握手，保留已确认 cursor。账号、标的和查询作用域通过真实 keyed iterator 隔离；
只需要重新读取的组件显式订阅目标参数，不能把静态组件 key 当作生命周期保证。
隐藏期间的轮询与实时退避等待各自拥有可取消的单一唤醒登记，任务取消立即释放，重复 poll 不累积回调；
恢复可见后再次隐藏仍可重新登记，不改变剩余分片、退避或补读策略。
论坛开关及帖子轮询共用这一隐藏等待，旧场次读取成功或失败都不能占据新目标。
“立即刷新”是显式整页刷新：点击后显示旋转图标与本地化“刷新中…”并禁用重复点击，先呈现反馈，再重新加载页面；
预览期保留该入口，自动同步只更新数据。减少动态效果偏好下停止图标旋转。

## 8. 文案、可访问性与安全

五语言为 `en`、`zh-CN`、`zh-TW`、`ja`、`ko`，Public 默认 `en`，文案由本 surface 的 Fluent 资源提供，新增或删除消息键
同步五份。共享层只提供语言选择机制，偏好键固定 `hv.lang`；正式规则正文来自已发布的规则 API。

页面保留跳转主内容入口、可见焦点和语义标题，真正 SPA 换页后聚焦主内容，原地刷新不抢焦点。竞价弹窗提供初始聚焦、
Tab 循环、背景滚动锁和关闭后焦点恢复，忙态遵守关闭守卫。成功/进行中反馈与错误反馈使用相应 `status`/`alert` 语义。
Markdown 原始 HTML 只作转义文本展示，链接遵守协议白名单；登录 Key 只用于当前认证流程并清理，敏感装备 URL 不进入
日志、审计或浏览器持久化缓存，数据库记录与外部凭据不进入本 crate。

## 9. 构建与维护

静态检查用 `bash ci/checks/check.sh i18n` 和 `cargo check --locked -p auction-web-public --target wasm32-unknown-unknown`；
`bash ci/release/web-bundle.sh public` 生成页面产物，上线还需重编并部署启用 `web-embed` 的 Public 宿主（见[开发指南](docs/guide/development.md)）。
页面变化同步本设计、模块说明、五语言及受影响表格/路由；共享组件变化核对两端，但不合并业务外壳。
技术栈和默认测试限制见[协作规范](AGENTS.md#web-规则)，验证限制登记在[状态页](docs/status.md#本轮静态检查)。
