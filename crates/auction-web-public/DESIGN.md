# Public 公开端设计

[系统设计](../../DESIGN.md) · [模块说明](README.md) · [文档导航](../../docs/README.md) · [独立的 Admin 设计](../auction-web-admin/DESIGN.md)

本页描述现有 Public 界面。源码、内嵌产物与线上页面可能版本不同，验收边界见[状态页](../../docs/status.md)。

## 1. 定位与隔离

公开端服务浏览者、竞买人及查看寄售结果的卖家。首要任务是找到装备、理解价格与截止时间、明确确认出价，
并在网络恢复后重新取得权威状态。它不是管理控制台，不展示凭据管理、Worker 操作、审计编辑或运行配置入口。

页面与交互由 [src/app/](src/app/) 拥有，API/实时恢复由 [src/api/](src/api/) 拥有；
专属样式为 [public.css](assets/public.css)，文案为 [i18n/](i18n/)。构建与嵌入入口见[模块说明](README.md)。
Public 不导入 Admin 页面/资源；共享层只提供通用机制，业务字段、列宽、竞价状态和文案留在本端。

## 2. 信息架构

| 页面族 | 入口示例 | 核心内容 |
| --- | --- | --- |
| 当前拍卖 | `/` | 世界、当前/预览/历史视图、场次摘要、分类筛选和拍品目录 |
| 拍卖历史 | `/auctions` | 世界与状态筛选、分页、拍品及竞价记录入口 |
| 装备详情 | `/lots/{lot_id}` | 装备安全投影、价格、截止时间、竞价历史和本人代理状态 |
| 竞价记录 | `/bidlog` | 场次/拍品筛选、玩家、来源与持久化竞价事实 |
| 成交历史 | `/history` | 装备、日期、价格、买卖方筛选及成交统计 |
| 论坛同步 | `/forum` | 同步开关、主题链接、固定帖子及真实处理楼层 |
| 公开内容 | `/rules`、`/blacklist`、`/compensation-pool` | 已发布规则、禁拍名单与补偿流水 |
| 登录与账户 | `/login`、`/me` | Public Key 登录、本人竞价及代理授权 |
| 服务说明 | `/status` | 静态产品说明，不另建实时连接 |

这里只概括页面职责，不替代完整路由清单。兼容别名、参数与后端 SPA 入口见
[路由契约](../../docs/contracts/routes.md) 和 [入口清单](../auction-http/src/assets/routes.rs)。
导航只突出正式入口，不能因为保留了别名就重复增加菜单项。

## 3. 外壳与布局

桌面信息层次：

```text
品牌 / 主导航                         世界 / 连接状态 / 刷新 / 语言 / 账户
─────────────────────────────────────────────────────────────────────
页面标题或拍卖摘要
筛选与上下文
拍品表、详情、账户或内容文档
分页与操作反馈
```

- 页头由 `public-shell` 持有，品牌使用强调色；当前导航项使用可见标记及 `aria-current`。
- 世界选择与账户状态保持可辨认，不让用户在不清楚当前世界或身份时提交竞价。
- 窄屏主导航折叠为两列菜单，展开状态通过 `aria-expanded` 表达；刷新、语言与账户保留独立控制区。
- 正文占用可用容器宽度。筛选和操作控件可换行，不能靠压缩到不可操作的尺寸维持单行。
- 规则正文使用自己的 `public-rules-page` 容器及安全 Markdown 块，不套入管理端卡片或编辑器布局。
- 黑名单页保留标题、名单或空态、分页；不显示额外的数据库 ID 说明段。表格仍显示 MoogleMail 玩家名称，
  不把姓名回退为内部数据库 ID；显示名不改变黑名单资格校验。

## 4. 视觉基底

沿用深色、紧凑、以数据为主的界面，不增加外部字体或主题框架。背景/容器层级、主次文字、金色品牌强调、
蓝色链接、语义状态及系统字体均使用[共享 base.css](../auction-web-shared/style/base.css)变量；具体值由样式维护。
状态颜色须配明确文字。`public-*` 布局和交互状态留在 `public.css`，不引入 `admin-*` 选择器；
间距、控件尺寸和断点复用共享体系，不为单页增加新的断点档位。

## 5. 表格与信息密度

表格遵守[布局契约](../../docs/table-layouts.md)：100% 容器宽、独立百分比列宽、窄屏保留表头/行列，
不改卡片或横向滚动。长文本提供完整值查看，复杂文本支持键盘/触控。金额对齐并提示完整 Credits，
表头/caption/可访问名称保留真实字段关系，不用 CSS 伪文本替代。装备链接只消费安全 DTO，Lite 空链接不伪造入口。

## 6. 竞价与代理交互

浏览器表达意图，不计算最终竞价结果，也不复刻领域状态机。

```text
选择拍品 → 读取权威状态/资格 → 输入金额 → 明确确认
                                       ↓
                             冻结 command_id 与负载
                                       ↓
                         提交 → 展示结果 → 重读权威快照
```

- 普通出价输入为不带后缀的 K 单位整数，发送前显示实际 Credits 金额和独立确认步骤。
- 代理表单显示 Fast/Slow、上限、配额与服务端 capability；最终阶段不能选择新建 Slow。
- 新输入遵守既有 1K 网格与 1B 上限，非法输入直接说明，不静默取整；服务端仍是最终权威。
- 提交中锁定重复动作。结果未知时保留原命令 ID、金额、模式与目标，不用刷新后的新状态改写旧请求。
- 成功面板展示服务端结果，随后更新权威读取；不能凭本地按钮点击就显示领先、成交或扣款成功。
- 表单状态以拍品及当前用户隔离；切换目标或身份不沿用上一用户的草稿和任务。
- 登录返回仅允许受限同源路径；`/me` 的竞价、代理分页与筛选恢复遵守既有 URL 契约。

## 7. 数据、时间与实时状态

- 初次读取、刷新、空结果、失败与能力缺失是不同状态；网络错误不能冒充匿名或空表。
- 筛选和分页由页面 owner 与 URL 双向同步，刷新、分享和浏览器前进/后退保持上下文。
- 倒计时使用服务端时间校准，仅作显示；拍卖截止、最终阶段和资格由后端决定。
- WebSocket 是已提交事件的通知入口，不承担竞价写入。sequence 与实体 version 不能混用。
- 跳号、重连或服务端要求重新读取时，通过 HTTP Catch-up 与权威快照恢复，不从通知负载猜测下一口价格。
- 页头连接徽章统一播报连接状态，不在每张表重复播报，也不因页面增加而复制连接。
- 正常静默不等于断线；浏览器不能因为看不到协议 Ping/Pong 而把空闲拍卖判为连接失败。
- `501 feature_not_supported` 属于档位限制，不提供无意义重试；规则缺失的 `rules_unavailable`
  需要发布正式正文，反复读取不能生成规则，也不能用示例正文伪装成已发布内容。

详细恢复、事件边界与错误码见 [事件契约](../../docs/contracts/events.md)、[HTTP 契约](../../docs/contracts/routes.md)。

## 8. 文案、可访问性与安全

五语言为 `en`、`zh-CN`、`zh-TW`、`ja`、`ko`，Public 默认 `en`。界面文案由本 surface 的 Fluent 资源提供；
新增或删除消息键时同步五份资源。共享层只提供语言选择机制，偏好键固定 `hv.lang`。
正式规则正文来自已发布的规则 API，不把界面译文当作规则正文来源。

页面保留跳转主内容入口、可见焦点和语义标题；真正 SPA 换页后聚焦主内容，原地刷新不抢焦点。
竞价弹窗提供初始聚焦、Tab 循环、背景滚动锁和关闭后的焦点恢复；忙态遵守关闭守卫，不重复提交。
成功/进行中反馈与错误反馈使用相应的 `status`/`alert` 语义。

Markdown 原始 HTML 只作转义文本展示，链接遵守协议白名单。登录 Key 只用于当前认证流程并按既有逻辑清理；
敏感装备 URL 不进入日志、审计或浏览器持久化缓存。数据库记录与外部凭据不进入本 crate。

## 9. 构建与维护

静态检查用 `just i18n-check` 和 `cargo check --locked -p auction-web-public --target wasm32-unknown-unknown`；
`just web-build-public` 生成页面产物，上线还需重编并部署启用 `web-embed` 的 Public 宿主，见[开发指南](../../docs/development.md)。
页面变化同步本设计、模块说明、五语言及受影响表格/路由；共享组件变化核对两端，但不合并业务外壳。
技术栈和默认测试限制见[协作规范](../../AGENTS.md#web-规则)，本次文档维护不意味着浏览器验收。
