# 포럼 댓글 입찰 규칙

포럼 댓글은 입찰 입력 경로이며, 최종 판정은 경매 데이터베이스를 기준으로 합니다.

- 댓글은 포럼의 게시 시각이 아니라 Worker가 가져온 시각으로 판정됩니다. 마감 전에 게시되었더라도 마감 후에 가져온 댓글은 거부될 수 있습니다.
- Worker는 폴링 간격(예: 300초)마다 주제를 스캔하며, 같은 스캔 안에서는 게시글 순서대로 새 댓글을 처리합니다.
- 소프트 마감 연장은 포럼 게시 시각이 아니라 가져온 시각부터 시작됩니다.
- 마감 직전에는 웹사이트 입찰 또는 프록시를 사용하고 포럼 댓글에 의존하지 마십시오.
- 주제가 설정된 페이지 한도를 초과하면 해당 경매의 포럼 가져오기가 전체적으로 실패하고 중단됩니다. 운영자가 처리할 때까지 웹사이트를 사용하십시오.
- 게시글을 수정해도 새 명령이 생성되지 않으며 이미 접수된 입찰도 취소되지 않습니다. 새 댓글을 게시하고 결과를 확인하십시오.
- 같은 스캔을 반복해도 중복 입찰되지 않습니다. 명령 ID는 주제, 게시글, 행, lot 코드에서 생성됩니다.
