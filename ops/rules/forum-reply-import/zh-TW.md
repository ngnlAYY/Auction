# 論壇回覆競價規則

論壇回覆是出價輸入管道，最終以拍賣資料庫為準。

- Worker 依匯入回覆的時刻判定，不依論壇顯示的發文時間判定。截止前發出、截止後才被匯入的回覆可能被拒絕。
- Worker 每隔輪詢間隔（例如 300 秒）掃描主題；同一輪內依樓層順序處理新回覆。
- 軟截止延長從匯入時刻起算，不從論壇發文時刻起算。
- 截止前最後幾分鐘請改用網站出價或代理，不要依賴論壇回覆。
- 主題超過設定頁數上限時，該場的論壇匯入整體失敗關閉；營運處理前請改用網站。
- 編輯貼文不會產生新命令，也不會撤銷已接受的出價；請重新回覆並核對結果。
- 重複掃描不會重複出價；命令 ID 由主題、貼文、樓層與 lot 代碼衍生。
