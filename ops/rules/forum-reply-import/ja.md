# フォーラム返信入札ルール

フォーラムの返信は入札の入力経路であり、最終的な判定はオークションのデータベースが基準です。

- 返信はフォーラムの投稿時刻ではなく、Worker が取り込んだ時刻で判定されます。締切前に投稿されても、締切後に取り込まれた返信は拒否されることがあります。
- Worker はポーリング間隔（例: 300 秒）ごとにトピックを走査し、同じ走査内では階層順に新しい返信を処理します。
- ソフト締切の延長は取り込み時刻から始まり、フォーラムの投稿時刻からは始まりません。
- 締切直前はウェブサイトの入札またはプロキシを使用し、フォーラム返信に依存しないでください。
- トピックが設定されたページ上限を超えると、そのオークションのフォーラム取り込みは全体として失敗し、停止します。運用者が対応するまでウェブサイトを使用してください。
- 投稿の編集は新しいコマンドを生成せず、受け付け済みの入札も取り消しません。新しい返信を投稿し、結果を確認してください。
- 同じ走査を繰り返しても二重入札にはなりません。コマンド ID はトピック、投稿、行、lot コードから生成されます。
