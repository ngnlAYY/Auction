# 论坛回帖竞价规则

论坛回帖是出价输入渠道，最终以拍卖数据库为准。

- Worker 按导入回帖的时刻判定，不按论坛显示的发帖时间判定。截止前发出、截止后才被导入的回帖可能被拒绝。
- Worker 每隔轮询间隔（例如 300 秒）扫描主题；同一轮内按楼层顺序处理新回帖。
- 软截止延长从导入时刻起算，不从论坛发帖时刻起算。
- 截止前最后几分钟请改用网站出价或代理，不要依赖论坛回帖。
- 主题超过配置页数上限时，该场的论坛导入整体失败关闭；运营处理前请改用网站。
- 编辑帖子不会产生新命令，也不会撤销已接受的出价；请重新回帖并核对结果。
- 重复扫描不会重复出价；命令 ID 由主题、帖子、楼层和 lot 代码派生。
