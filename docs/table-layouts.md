# 表格列宽分配

每张业务表按字段预计内容独立分配列宽。以下数值按实际表头顺序排列，单位均为百分比，每行
合计 100。业务组件在自己的 `TableColumns` 调用中拥有比例；共享组件仅归一化并输出
`colgroup`，不得在共享层引入业务列模板。新增列或改变字段展示时，同步更新调用与本登记。

所有表格占满所在容器，保持表头、行结构和列顺序。长装备名、玩家名、ID、错误和极端金额
允许单行省略，并通过完整文本提示查看；操作按钮在自己的列内换行。窄屏继续按比例收缩，
不增加横向滚动、固定表格最小宽度或卡片视图。

## Markdown 与调试边界

Markdown 表格没有固定业务字段。渲染器以表头和前 32 行内容的第 75 百分位长度估算权重，
ASCII 字符记 1，其他字符记 2，每格最多读取 96 字符，每列权重限制在 8–48 后归一化。
这样既照顾较长说明，也避免单条超长 URL 占据整张表。内容或语言变化时重新计算。

比例调整使用 Chromium 的实际表格像素宽度与截图核对，按表格容器宽度计算而非页面宽度。
真实数据缺失的预览、账户等分支需区分结构核对与有数据页面验证；空表不能证明长内容显示效果。
本次布局调整不改变 HTTP、竞价、结算或后台命令契约。
