# 数据库迁移

`postgres/` 和 `sqlite/` 分别保存两种数据库的迁移脚本。它们表达同一套逻辑结构，但允
许使用各自的数据库方言、索引和锁语义。迁移只允许追加，已经发布的文件禁止修改。竞价
事务的锁、唯一约束、审计事件和 outbox 语义必须与
[`docs/architecture.md`](../docs/architecture.md) 一起评审。

第一份结构迁移会在完成 Auction-BF 契约盘点后分别提交到两个目录。本阶段不会把旧数据库
表未经审计地复制到新系统。

除非用户明确要求，迁移目录不编写或运行功能测试用例；迁移结构变更仍需通过编译检查、
静态检查和人工审阅确认。
